# Fundamentos de Programación

Repositorio centralizado para el estudio de sintaxis, estructuras de datos y algoritmos en múltiples lenguajes de programación. Enfocado en Backend y Análisis de Datos.

## Lenguajes Incluidos
* Python (Data Analysis & Backend)
* Java (Backend Empresarial)
* JavaScript / TypeScript (Backend con Node.js)
* Go (Microservicios)
* Bash (Automatización en Linux)
