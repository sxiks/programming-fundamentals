# Theory

This directory contains the conceptual knowledge that supports the practical examples found throughout the repository.

The goal of these documents is not to replace coding practice, but to provide clear explanations of the fundamental concepts used in programming.

## Purpose

The files in this directory explain:

* What a concept is
* How it works
* When it should be used
* Common mistakes
* Best practices

## Learning Order

Follow the same sequence defined in the learning path:

1. Variables and Types
2. Functions
3. Control Structures
4. Data Structures
5. Object-Oriented Programming
6. Functional Programming

## Relationship with Fundamentals

Theoretical documents explain concepts.

Code examples demonstrate concepts.

Exercises reinforce concepts.

All three parts should be studied together.
