# Object-Oriented Programming Basics

## What Is OOP?

Object-Oriented Programming is a paradigm that organizes software around objects.

Objects combine:

* Data
* Behavior

## Core Concepts

### Class

Blueprint for creating objects.

### Object

Instance of a class.

### Encapsulation

Combining data and behavior together.

### Inheritance

Creating specialized versions of existing classes.

### Polymorphism

Allowing different objects to share common behavior.

## When to Use

Use OOP when:

* Modeling real-world entities
* Managing related data and behavior
* Building larger systems

## Common Mistakes

* Overusing inheritance
* Creating large classes
* Modeling everything as an object

## Best Practices

* Prefer simple classes
* Keep responsibilities clear
* Use composition when appropriate
* Focus on readability
