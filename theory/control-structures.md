# Control Structures

## What Are Control Structures?

Control structures determine the order in which instructions are executed.

They allow programs to make decisions and repeat actions.

## Types

### Conditionals

Used for decision making.

Examples:

* if
* else
* switch

### Loops

Used for repetition.

Examples:

* for
* while

## How It Works

Programs evaluate conditions.

Depending on the result:

```text
True → Execute
False → Skip
```

## When to Use

Use control structures when:

* Decisions are required
* Tasks must be repeated
* Different outcomes are possible

## Common Mistakes

* Infinite loops
* Deep nesting
* Complex conditions
* Duplicate logic

## Best Practices

* Keep conditions simple
* Avoid excessive nesting
* Prefer readability
* Break large logic into functions
