# Functions

## What Is a Function?

A function is a reusable block of code designed to perform a specific task.

Functions help reduce duplication and improve organization.

## How It Works

Functions can:

* Receive inputs (parameters)
* Perform operations
* Return outputs

General flow:

```text
Input → Process → Output
```

## When to Use

Use functions when:

* Logic is repeated
* A task has a clear responsibility
* Code becomes difficult to read

## Common Mistakes

* Creating very large functions
* Mixing multiple responsibilities
* Using unclear names
* Excessive nesting

## Best Practices

* Keep functions small
* Give functions a single responsibility
* Use descriptive names
* Prefer clarity over cleverness
