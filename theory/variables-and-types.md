# Variables and Types

## What Is a Variable?

A variable is a named location in memory used to store data.

Variables allow programs to keep information that can be reused and modified during execution.

## What Is a Data Type?

A data type defines the kind of value stored in a variable.

Common data types include:

* Integer
* Float
* String
* Boolean

## How It Works

A variable combines:

* Name
* Value
* Type

Example:

```text
age = 25
```

Variable name:

```text
age
```

Stored value:

```text
25
```

Type:

```text
Integer
```

## When to Use

Variables should be used whenever information needs to be stored, reused, or updated.

Examples:

* User names
* Scores
* Prices
* Configuration values

## Common Mistakes

* Using unclear names
* Reusing variables for unrelated purposes
* Ignoring data types
* Creating unnecessary variables

## Best Practices

* Use descriptive names
* Keep variables focused on one purpose
* Prefer readability over short names
* Choose meaningful data types
