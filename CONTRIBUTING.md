# Contributing

## Repository Philosophy

This repository is focused on progressive learning.

Examples must:

- Teach one concept at a time.
- Follow the learning path.
- Remain beginner friendly.
- Prefer clarity over optimization.

## Structure Rules

Fundamentals contain concepts.

Exercises contain practice.

Exercises must never introduce new concepts.

## Naming Convention

Examples:

01-variables.py
02-functions.py

Files use:

- lowercase
- hyphen-separated names
- numeric prefixes
