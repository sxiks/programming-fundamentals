# docs/

Documentación de navegación y mapas conceptuales de `programming-fundamentals`. Este directorio no contiene un curso teórico — el contenido que enseña conceptos vive en `fundamentals/` y `exercises/` de cada lenguaje.

## Contenido

| Archivo | Propósito |
| --- | --- |
| `learning-path.md` | Fuente de verdad pedagógica del repositorio. Define los ocho pasos de la ruta de aprendizaje, su orden y sus dependencias. |
| `study-guide.md` | Guía general de estudio. |

## Regla

Cualquier duda sobre "qué sigue" o "en qué orden" se resuelve en `learning-path.md`, no en este README ni en ningún otro documento. Este directorio no duplica esa información — la referencia.
