# python/exercises/

Ejercicios de práctica para los fundamentos de Python. Antes de resolver cualquier ejercicio, revisa el paso correspondiente en [`docs/learning-path.md`](../../docs/learning-path.md).

## 01-intro/

Ejercicios guiados de un solo concepto, con alcance reducido.

| Archivo | Concepto |
| --- | --- |
| `01-conditionals-practice.py` | Condicionales (Paso 05) |
| `02-loops-practice.py` | Bucles (Paso 05) + Listas (Paso 07) |
| `03-lists-practice.py` | Listas (Paso 07) + Condicionales (Paso 05) |

## 02-challenges/

Retos de integración: combinan dos o más conceptos ya vistos, con mayor autonomía, sin introducir ninguno nuevo.

| Archivo | Conceptos integrados |
| --- | --- |
| `01-grades-report.py` | Bucles + Condicionales (05) + Listas (07) |
| `02-contact-book.py` | Funciones (06) + Diccionarios (07) + Bucles/Condicionales (05) |

## Regla

Ningún ejercicio de esta carpeta introduce un concepto que no haya sido cubierto antes en `fundamentals/`.
