# python/fundamentals/

Python es el lenguaje principal de este repositorio. Esta carpeta cubre los ocho pasos de la Parte I del PDF, organizados por tema en subcarpetas. El orden y las dependencias entre esos pasos viven en una sola fuente de verdad: [`docs/learning-path.md`](../../docs/learning-path.md). Este README no repite esa información — solo indica qué subcarpeta corresponde a cada paso.

## Estado por subcarpeta

| Subcarpeta | Paso(s) del Learning Path | Estado |
| --- | --- | --- |
| `syntax/` | 01 Sintaxis, 02 Variables, 03 Tipos de Datos, 04 Operadores | Cubierto |
| `control_structures/` | 05 Estructuras de Control | Cubierto |
| `functions_modules/` | 06 Funciones | Cubierto |
| `data_structures/` | 07 Estructuras de Datos | Cubierto |
| `oop/` | 08 Paradigmas Básicos — Orientado a Objetos | Cubierto |
| `functional/` | 08 Paradigmas Básicos — Funcional | Cubierto |

**Nota sobre el paradigma Imperativo:** no tiene una subcarpeta ni un archivo dedicado. Es el paradigma implícito en todo el código de este repositorio — `oop/` y `functional/` existen para mostrar paradigmas *alternativos* al imperativo, no para reemplazarlo.

## Cómo estudiar esta carpeta

Sigue el orden de `docs/learning-path.md`, no el orden alfabético de las subcarpetas. Dentro de cada subcarpeta, los archivos están numerados en el orden en que deben leerse.
