# javascript/fundamentals/

JavaScript es el lenguaje secundario de este repositorio. Esta carpeta cubre los ocho pasos de la Parte I del PDF, organizados por tema en subcarpetas. El orden y las dependencias entre esos pasos viven en una sola fuente de verdad: [`docs/learning-path.md`](../../docs/learning-path.md).

## Estado por subcarpeta

| Subcarpeta | Paso(s) del Learning Path | Estado |
| --- | --- | --- |
| `syntax/` | 01 Sintaxis, 02 Variables, 03 Tipos de Datos, 04 Operadores | Cubierto |
| `control_structures/` | 05 Estructuras de Control | Cubierto |
| `functions_modules/` | 06 Funciones | Cubierto |
| `data_structures/` | 07 Estructuras de Datos | Cubierto |
| `oop/` | 08 Paradigmas Básicos — Orientado a Objetos | Cubierto |
| `functional/` | 08 Paradigmas Básicos — Funcional | Cubierto |

**Nota sobre el paradigma Imperativo:** igual que en Python, no tiene subcarpeta propia — es el paradigma implícito en el resto del código.

## Más allá del Learning Path

`dom_manipulation/` es contenido específico de JavaScript como lenguaje de navegador (introducción al DOM, eventos de mouse, eventos de formulario). No corresponde a ningún paso de la Parte I del PDF — es una extensión propia de este lenguaje, no parte de la progresión común con Python.

## Cómo estudiar esta carpeta

Sigue el orden de `docs/learning-path.md`. Dentro de cada subcarpeta, los archivos están numerados en el orden en que deben leerse.
